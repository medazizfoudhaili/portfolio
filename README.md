# Mouhamed Aziz Foudhaili - DevOps Engineer Portfolio

This is a personal portfolio website showcasing the skills, experience, and projects of Mouhamed Aziz Foudhaili, a DevOps Engineer student at ENSIT.

## Built With

- HTML5, CSS3
- Google Fonts (Inter, Space Grotesk)
- Responsive design, mobile-first
- Dark/Light theme support via `prefers-color-scheme`

## Sections

- **Profile** - Professional summary and contact information
- **Education** - Academic background at ENSIT and IPEIB
- **Experience** - Internships at Corail Technologies and Poulina Group Holding
- **Projects** - GitOps/Observability, Serverless AWS, IoT Health Monitoring, Freelance Platform
- **Skills** - Technical skills including Docker, Kubernetes, Terraform, Ansible, AWS, etc.
- **Certifications** - AWS Academy, Cisco CCNA, Python Developer Certificate
- **Languages** - Arabic (native), French (B2/C1), English (B2)
- **Qualities** - Teamwork, communication, problem-solving, adaptability

## Deployment

This site is ready for GitHub Pages deployment. To deploy:

```bash
git init
git add .
git commit -m "Initial portfolio site"
# Create GitHub repo and push
# Enable GitHub Pages in repo settings
```

The site uses a responsive grid that adapts from mobile (1 column) to desktop (3 columns for projects).
